# Pace Baixo

Landing page de alta conversão do **Pace Baixo**, grupo gratuito de ofertas de tênis de corrida.

## Sobre

Página única (HTML/CSS/JS puro, sem dependências) focada em conversão para entrada no grupo de WhatsApp. Inclui:

- Barra de urgência com contador regressivo
- Prova social (depoimentos + selos de confiança)
- Seção "Como funciona em 3 passos"
- Mockup do WhatsApp com oferta
- Garantia / risco zero
- FAQ
- CTA fixo no mobile
- SEO e Open Graph configurados

## Arquivos

| Arquivo | Descrição |
|---|---|
| `index.html` | A landing page completa (tudo embutido) |
| `logo-web.png` | Logo com fundo transparente (usada no site) |
| `logo.png` | Logo original (fundo escuro, usada no compartilhamento) |

## Rodar localmente

Basta abrir o `index.html` no navegador, ou servir a pasta:

```bash
npx serve .
```

## Deploy

Projeto estático, pronto para deploy na Vercel (ou qualquer host estático). Sem build necessário.
